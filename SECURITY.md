# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Unbait, please report it by emailing:

**unbait@in-flux.app**

Please **do not** open a public GitHub issue for security concerns.

## What Qualifies

- API key exposure or leakage
- Cross-site scripting (XSS) vulnerabilities
- Data leaks (user data leaving the extension unexpectedly)
- Permission escalation
- Any way for a website to access extension storage or settings

## Response Time

Unbait is a hobby project maintained by one person. I take security seriously, but please allow up to **7 days** for an initial response. I'll do my best to address confirmed vulnerabilities as quickly as possible.

## Scope

This policy covers the Unbait browser extension code. Third-party AI provider APIs (Anthropic, OpenAI, Google) have their own security policies and are outside the scope of this project.

Thank you for helping keep Unbait safe.
